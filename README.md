# AURORA resources

Public mini app, theme and widget packages for AURORA. Game modes are bundled with the application and updated only through EXE application updates.

Application source, USB control modules, user data and credentials are not published here. The three catalog.json files list versioned, SHA-256 checked packages. Preserve previously published non-game packages.
