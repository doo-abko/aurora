# AURORA resources

Public mini app, theme and widget distribution packages for AURORA. Game modes are bundled with the application and updated only through EXE application updates.

Application source, USB control modules, user data and account credentials are not published here. Package filenames include versions and SHA-256 hashes. Preserve previously published non-game packages.
